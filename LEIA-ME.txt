DROGARIA ONLINE — MASTER 1.5 — PWA INSTALAVEL (ATALHO PROFISSIONAL)

ATENCAO: Este pacote cria um PWA instalavel no Android, mas funciona como um launcher.
Ao tocar em Abrir Drogaria, o navegador abre a implantacao existente no Google Apps Script.
O sistema de compra NAO foi migrado para hospedagem propria. Push e notificacoes nao estao incluidos nesta fase.

INSTALACAO
1. NAO ALTERE Codigo.gs, Index.html ou Admin.html do Google Apps Script.
2. Em config.js, substitua COLE_AQUI_A_URL_EXEC_DA_DROGARIA pela URL real e completa da implantacao da Drogaria (terminada em /exec). Nao use o link /dev e nao use ?admin=1.
3. Crie um repositorio SEPARADO no GitHub (ex.: drogaria-online-pwa).
4. Envie para a raiz os arquivos index.html, config.js, manifest.webmanifest, service-worker.js e a pasta icons/ com as imagens.
5. Settings > Pages > Deploy from a branch > main / (root). Aguarde o GitHub Pages publicar.
6. Abra o endereco HTTPS do GitHub Pages no Chrome Android. No menu do navegador escolha Instalar aplicativo/Adicionar à tela inicial.
7. Teste Abrir Drogaria, cadastro, carrinho e pedido no Apps Script como antes.

LIMITACOES
- Se nao configurar config.js o botao Abrir Drogaria avisa sobre a configuracao ausente.
- A plataforma pode abrir o Apps Script no navegador, em vez de no mesmo PWA.
- Carrinho, login e pedidos dependem de conexao e do Google Apps Script.
- Nao ha Firebase Push nem sincronizacao offline de pedidos nesta fase.
- Nunca coloque senha, token Firebase, chave de API secreta ou credenciais no GitHub.
- Nao copie arquivos nem configuracoes do Ideal Ofertas.
